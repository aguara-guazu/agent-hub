AGENT HUB · REDISEÑO DE UX/UI · v1

Un lugar para cada cosa, y cada cosa en su lugar.

La app pasa de seis secciones con tres niveles de navegación a ocho destinos planos, una sola página de ajustes y una regla para cada decisión de interfaz. Este lienzo es la referencia para diseñar y para que los agentes que implementan el front no tengan que adivinar.

Qué cambia y por qué

ANTES Tres niveles de navegación apilados

Barra lateral, pestañas de Memoria y diez pestañas de proyecto que se cortan a 1440 px.

→ Barra lateral + máximo 5 pestañas
ANTES 33 modales, varios repetidos

«Vincular» y «Agregar vínculo» abren el mismo diálogo. Cada entidad tiene su modal de «Editar».

→ Edición en panel lateral; modal solo para crear
ANTES Confirmaciones para todo

«Ejecutar ahora», «Pausar» o «Cancelar» piden confirmación aunque se puedan revertir.

→ Acción inmediata + «Deshacer»
ANTES Ajustes en dos lugares

Ajustes y «Fuentes y ajustes» de Memoria; Jira se configura en ambos.

→ Una sola página de Ajustes por secciones
ANTES El mismo aviso en cada tarjeta

Cuatro bloques rojos idénticos de «Falta autorizar la cuenta» y el enlace de credenciales repetido en cada server.

→ Un aviso por página que agrupa los casos
ANTES Textos que explican la interfaz

Subtítulos, notas y bloques «Cómo se organizan» que nadie lee; voseo, tuteo y valores en inglés mezclados.

→ Voseo, etiquetas traducidas, cero texto de relleno

Seis principios

01
Un lugar para cada cosa

Cada concepto vive en un solo destino. Si algo aparece en dos lados, uno es el dueño y el otro solo enlaza.

02
Dos niveles de navegación como máximo

Barra lateral y, dentro de una ficha, hasta cinco pestañas. Nunca pestañas dentro de pestañas.

03
Editar donde se ve

Seleccionar una fila abre su panel lateral, con los campos editables ahí mismo. El modal queda para crear algo nuevo.

04
Deshacer en lugar de confirmar

Si una acción se puede revertir, se ejecuta y ofrece «Deshacer». Solo se confirma lo que borra datos sin vuelta atrás.

05
Lo que necesita atención sube a Inicio

Autorizaciones, reinicios, propuestas y revisiones se juntan en una bandeja. Las vistas muestran estado, no alarmas.

06
La interfaz no se explica a sí misma

Nada de párrafos de ayuda permanentes. Si algo necesita explicación, va en el estado vacío o en un tooltip.
